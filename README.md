# RetailGenie

RetailGenie is a prototype analytics platform for retail stores.

The service analyzes customer behavior and helps optimize product assortment and pricing.

## Technologies

- Python
- FastAPI
- SQLite
- SQLAlchemy
- HTML Dashboard

## Features

- Customer management
- Product management
- Order tracking
- Sales analytics
- Popular product analysis
- Revenue statistics

## Run the project

```bash
uvicorn main:app --reload
