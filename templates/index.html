How this prototype works
FastAPI + SQLite with seed data for demo exploration.

RetailGenie tracks customers, products, orders, and order items. The backend exposes REST endpoints for each entity plus analytics endpoints for:

  • Top selling products (`/analytics/popular-products`)
  • Total revenue (`/analytics/revenue`)
  • Most active customers (`/analytics/customer-stats`)

This dashboard is a tiny HTML shell that calls those APIs directly via JavaScript. Replace it with your own frontend or BI tool as you evolve the platform.
